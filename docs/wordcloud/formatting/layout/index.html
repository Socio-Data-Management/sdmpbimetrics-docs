Layout

The Layout card controls the typography and the placement of the words.

Properties​

PropertyDescriptionDefault
FontFont family of the wordsSegoe UI
Min font sizeSize of the smallest word (at least 4)12
Max font sizeSize of the largest word80
Size scaleHow a value maps to a size: Linear, Square root or LogarithmicSquare root
RotationHorizontal only, Horizontal + Vertical, or Free anglesHorizontal + Vertical
SpacingPadding around each word, in pixels2
SpiralArchimedean or Rectangular search path used to find a free spotArchimedean
Random seedSeeds the random choices of the layout (word rotation, starting positions). The same seed gives the same cloud on every reload; 0 gives a new random cloud each time1

Choosing a size scale​

  • Linear keeps the proportions of the data but lets one dominant word crush the others.
  • Square root is a good compromise and the default.
  • Logarithmic flattens strong differences — useful when the top words are far above the rest.
Reproducible layout

The cloud uses random choices (word rotation, starting positions). With the default Random seed of 1 the layout is identical on every reload. Change the number to get another arrangement you like, or set 0 for a different one each time. The layout still depends on the data order, the font and the size of the visual.

Shape and mask mode

When a Background shape or image mask is selected, the words are placed by a different engine: Spiral does not apply, and Rotation is only honored when Respect rotation is on.
