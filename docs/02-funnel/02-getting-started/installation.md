# Installation

## From AppSource

1. Open your Power BI report
2. In the Visualizations pane, click the **...** (Get more visuals)
3. Search for **"SDM Funnel"**
4. Click **Add**

The visual will appear in your Visualizations pane.

## From a .pbiviz File

If you received a `.pbiviz` file directly:

1. In Power BI Desktop, go to **File > Import > Power BI Visual**
2. Select the `.pbiviz` file
3. The visual will be added to your Visualizations pane
